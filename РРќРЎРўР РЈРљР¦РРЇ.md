# Автотесты SauceDemo — Java + Selenium + TestNG
## Пошаговая инструкция по установке и запуску

---

## Что нужно установить (один раз)

### Шаг 1 — Установить Java 11+

1. Открыть https://adoptium.net
2. Скачать **Temurin 11 (LTS)** для вашей ОС
3. Запустить установщик, нажать Next → Next → Install
4. **Проверить установку:** открыть терминал (командную строку) и ввести:
   ```
   java -version
   ```
   Должно вывести что-то вроде: `openjdk version "11.0.XX"`

---

### Шаг 2 — Установить Maven

Maven — это инструмент сборки Java-проектов. Он сам скачивает все нужные библиотеки.

**Windows:**
1. Открыть https://maven.apache.org/download.cgi
2. Скачать `apache-maven-3.9.X-bin.zip`
3. Распаковать в `C:\Program Files\Maven\`
4. Открыть: Панель управления → Система → Дополнительные параметры системы
   → Переменные среды → Path → Изменить → Добавить: `C:\Program Files\Maven\bin`
5. Перезапустить терминал
6. **Проверить:**
   ```
   mvn -version
   ```
   Должно вывести: `Apache Maven 3.9.X`

**macOS (через Homebrew):**
```bash
brew install maven
mvn -version
```

---

### Шаг 3 — Установить Google Chrome

Скачать последнюю версию с https://google.com/chrome

> **Важно:** WebDriverManager сам скачает подходящий ChromeDriver.
> Ничего устанавливать дополнительно не нужно.

---

### Шаг 4 — Установить IntelliJ IDEA (рекомендуется)

1. Открыть https://www.jetbrains.com/idea/download
2. Скачать **Community Edition** (бесплатная)
3. Установить с настройками по умолчанию

## Открыть проект

### Вариант А — Через IntelliJ IDEA

1. Запустить IntelliJ IDEA
2. На стартовом экране: **Open** → выбрать папку `saucedemo_java`
3. IntelliJ предложит: *"Maven project detected"* → нажать **Trust Project**
4. Подождать пока IDEA скачает зависимости (внизу будет полоса прогресса)
5. Когда закончит — справа появится вкладка **Maven** с проектом

---

### Вариант Б — Через терминал (без IDE)

```bash
# Перейти в папку проекта
cd saucedemo_java

# Скачать все зависимости (первый раз займёт 2-5 минут)
mvn dependency:resolve
```

---

## Запуск тестов

### Запуск ВСЕХ тестов — из IntelliJ IDEA

1. В правой панели открыть **Maven** → `saucedemo_java` → **Lifecycle**
2. Двойной клик на **test**
3. Внизу откроется консоль с результатами

**Или через терминал внутри IDEA** (View → Tool Windows → Terminal):
```bash
mvn test
```

---

### Запуск ВСЕХ тестов — из системного терминала

```bash
cd saucedemo_java
mvn test
```

---

### Запуск с ОТКРЫТЫМ браузером (видно что происходит)

```bash
mvn test -Dheadless=false
```

> По умолчанию `headless=false` — браузер открывается. Это удобно при первом
> запуске — видно как тесты кликают по странице.

---

### Запуск БЕЗ браузера (быстрее, для CI/CD)

```bash
mvn test -Dheadless=true
```

---

### Запуск ОДНОГО класса тестов

```bash
# Только тесты авторизации
mvn test -Dtest=LoginTest

# Только тесты корзины
mvn test -Dtest=CartTest

# Только тесты оформления заказа
mvn test -Dtest=CheckoutTest
```

---

### Запуск ОДНОГО конкретного теста

```bash
# Один тест по имени метода
mvn test -Dtest=LoginTest#testLoginStandardUser

# Несколько тестов
mvn test -Dtest=LoginTest#testLoginStandardUser+testLogout
```

---

### Запуск в Firefox

```bash
mvn test -Dbrowser=firefox
```

> Для Firefox нужно установить браузер Mozilla Firefox с официального сайта.
> GeckoDriver скачается автоматически через WebDriverManager.

## Просмотр результатов

### HTML-отчёт ExtentReports

После запуска открыть файл:
```
saucedemo_java/test-output/ExtentReport.html
```
Открыть через любой браузер (двойной клик на файл).

Отчёт содержит:
- Общую статистику (Passed / Failed / Skipped)
- Каждый тест с шагами
- Скриншоты при падении тестов
- Системную информацию

---

### Стандартный отчёт TestNG

```
saucedemo_java/test-output/index.html
```

---

### Скриншоты при падении

```
saucedemo_java/screenshots/
```
Каждый файл называется: `ИмяТеста_дата_время.png`

## Частые проблемы и решения

**Ошибка: `java: error: release version 11 not supported`**
→ В IntelliJ: File → Project Structure → SDK → выбрать Java 11

**Ошибка: `ChromeDriver executable needs to be in PATH`**
→ WebDriverManager должен скачать его автоматически.
  Проверьте интернет-соединение и попробуйте запустить снова.

**Ошибка: `mvn: command not found`**
→ Maven не добавлен в PATH. Переустановите по инструкции Шаг 2.

**Тесты запускаются, но браузер не открывается**
→ Добавьте флаг: `mvn test -Dheadless=false`

**Тест падает с `NoSuchElementException`**
→ Элемент не найден на странице. Проверьте интернет и доступность saucedemo.com.
  Возможно, сайт обновил вёрстку — нужно обновить локаторы в Page Object.
