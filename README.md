## Запуск проекта

### Предварительные требования

- Установленный **JDK 11** или выше
- Установленный **Apache Maven**
- Браузер **Google Chrome** (драйвер загружается автоматически)

### Инструкция

1. Клонировать репозиторий:
```bash
   git clone https://github.com/revunov168-ux/saucedemo-autotests.git
   cd saucedemo-autotests
```

2. Запустить все тесты:
```bash
   mvn clean test
```

3. Запустить тесты через конфигурацию TestNG:
```bash
   mvn clean test -DsuiteXmlFile=testng.xml
```

Драйвер браузера подгружается автоматически с помощью WebDriverManager — ручная установка ChromeDriver не требуется.

## Отчёты о тестировании

После выполнения тестов формируется HTML-отчёт ExtentReports с детальной информацией о каждом сценарии: статус прохождения, шаги, скриншоты при падении. Отчёт доступен в каталоге с результатами прогона.

## Применённые подходы и практики

- **Page Object Model** — каждая страница приложения описана отдельным классом, что упрощает поддержку и переиспользование кода
- **Параметризация** — запуск одних и тех же тестов с разными наборами данных через возможности TestNG
- **Автоматическое управление драйверами** — WebDriverManager избавляет от ручной настройки
- **Наглядная отчётность** — ExtentReports для визуализации результатов
- **Чистая структура** — разделение тестовой логики и описания страниц

## Тестовые учётные данные

SauceDemo предоставляет открытые учётные записи для тестирования:

- **Логин:** `standard_user` (и другие: `locked_out_user`, `problem_user`, `performance_glitch_user`)
- **Пароль:** `secret_sauce`
